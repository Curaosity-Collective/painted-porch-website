# PPS Skills in This Repository

This directory records the PPS organizational skills that affect website work. The managed skill package remains the canonical operating source; repository entries make its trigger, handoffs, and implementation expectations visible to contributors working in this codebase.

| Skill | Use It When | Repository Reference |
|---|---|---|
| `speaking-event-engagement` | Building or changing the attendee continuation experience around an approved keynote, workshop, webinar, or conference session | [Speaking Event Engagement](./speaking-event-engagement.md) |

## Adding or Updating a Skill Record

Add a repository record when a managed PPS skill changes how this website is planned, built, tested, or released. Keep the entry concise and point to the managed skill as the authority. Do not duplicate event-specific pricing, routes, access methods, scores, provider settings, or other temporary configuration in the registry.
